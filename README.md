<h1>Movie Administration App</h1>

<p>The main objective of the Movie Administration App is to create, remove, update and delete movie data for an movie review website. The application will allow staff and critics to log into their appropriate roles to manage movie data and reviews respectively. It will update data in the database, which will be displayed to users on the front end through an API.</p>
